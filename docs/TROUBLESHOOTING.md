# 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| 범주 목록 실패 | 카카오톡 실행·로그인, 실제 실행 경로, 본인 프로필의 chatfolder.edb |
| 기본 범주 누락 | 사용자 생성 범주만 지원하며 전체/즐겨찾기/안읽음 등은 미검증 |
| 범주 삭제 후 다시 생성 | 새 ID이므로 folders 확인 후 scope로 재선택 |
| 방 수집 실패 | 키가 로드되지 않았거나 구조가 다를 수 있음. 사용자가 방을 열고 재시도 |
| 카카오톡 재시작 | executable은 다시 찾음. pids 설정은 직접 갱신 필요 |
| dot에 도구가 없음 | 연결 PC의 새 로컬 작업에서 MCP/CLI 호출 확인 |

프로그램은 방을 자동으로 열거나 메시지를 보내지 않습니다. 전체 조회에는 모든 선택 방의 최신 수집 성공이 필요합니다. `bridge_status` 또는 `status`에서 실패한 방을 확인하세요.

범주 ID를 따라 이름 변경을 추적합니다. `scope` 인자는 현재 선택을 추가하지 않고 완전히 교체하며 인자를 비우면 수집을 멈춥니다.

프로세스 종료 감지는 구현되어 있습니다. 프로세스가 남는 내부 로그아웃은 미검증입니다. 로그아웃이 과거 DB를 해독 불가능하게 만든다고 가정하지 않습니다.

오류 보고는 버전·오류 종류·실패 단계로 시작합니다. 원본 DB·개인 설정·키·인증정보·대화·실제 계정 경로는 공개하지 마세요.
