1

카카오톡 데이터 연결

이 PC의 카카오톡이 설치되어 있고 로그인되어 있어야 합니다.

폴더를 찾은 뒤 사용할 계정을 직접 선택하세요.

선택한 계정 폴더 경로입니다. 필요한 경우 직접 입력할 수 있습니다.

경로 세부 설정

읽은 대화를 보관할 로컬 DB입니다. 카카오톡 계정 폴더 밖에 저장하세요.

설정을 확인하는 중입니다.
2

읽을 범주 선택

카카오톡에 직접 만든 사용자 지정 범주를 불러옵니다.

설정을 저장한 뒤 범주를 불러오세요.

체크한 범주 전체가 새로운 읽기 범위가 됩니다. 모두 해제하고 저장하면 대화 읽기를 중지합니다.

범주 목록을 아직 불러오지 않았습니다.
3

조회 확인

버튼을 누르면 저장한 범주의 최근 메시지를 최대 20건 읽습니다.

이 화면을 열기만 하면 대화를 읽지 않습니다.

dot 프로필에서 Computers → Your computer → Allow access를 선택합니다. 이미 허용했다면 다시 설정하지 않아도 됩니다.

2

PC를 온라인으로 두고 앱을 열어 둔 상태에서 아래 요청으로 실제 호출을 확인하세요.

연결된 내 PC에서 OpenKKT 읽기 도구로 카카오톡 사용자 지정 범주의 이름·채팅방 수·선택 여부를 확인해줘. 대화 본문은 읽지 말고 실제 실행 성공 여부도 알려줘.

MCP·skill 등록은 이 PC 기준입니다. 비서에서 실제 호출이 성공하는지 별도로 확인해야 하며, 새 메시지의 자동 감지·응답은 별도 연결이 필요합니다.
